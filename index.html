How it was built

  1. The split is by patient. Beats from one person look alike, so a random split lets a model memorise people and score high for the wrong reason. Training uses the 22 records of the standard DS1 set, testing uses the 22 different records of DS2 (de Chazal et al., 2004). Design choices were made with patient-wise cross-validation inside DS1.
  2. Cleaning. A 200 ms and a 600 ms median filter remove baseline drift, then a 45 Hz low-pass takes out mains and muscle noise. Each beat is cut from 96 samples before the R peak to 144 after, at 360 Hz.
  3. Compare with the patient's own beats. Beat shape differs a lot between people, so absolute shape generalises badly. For every beat the model measures how far it is from the median of that patient's previous 30 beats: correlation, error, width and peak position. It also gets nine timing numbers (gaps before and after, relative to the recent average). Everything is computed from the past only, so it could run live.
  4. Model. A small neural network, 15 inputs, two hidden layers (128 and 64), five copies trained from different seeds and averaged. Square-root class weights, input noise and dropout. It is small enough to train on one CPU core.
  5. In the browser. The feature code and the network are under 100 lines of JavaScript with no libraries. A test checks both against the Python implementation on real beats.
  6. What did not work. A convolutional network on the raw waveform fit the training patients almost perfectly and scored 86.2% on the test patients, worse than a plain tree model. It had learned who the patients were. It also latched onto average heart rate, which identifies a person, so that input was removed from everything that followed.

What it is not

  • Not a medical device and not a diagnosis. It is a research exercise on a 1970s-80s dataset.
  • Beat positions come from the database annotations. The model sorts beats, it does not find them.
  • One lead (MLII), 47 patients, 48 half-hour recordings. Other leads, devices and populations will do worse.
  • Supraventricular beats are the hard class, and the scorecard says so.
